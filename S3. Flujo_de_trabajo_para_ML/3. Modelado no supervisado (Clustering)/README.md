# Modelado No Supervisado (Clustering)

Actividad del Integrante 3 para implementar K-Means sobre el dataset hotelero preparado para Machine Learning.

## Archivos

1. `1_notebook_clustering.ipynb`
   - Notebook con carga de datos, seleccion de variables, K-Means, Metodo del Codo, Coeficiente de Silueta e interpretacion.

2. `graficas/`
   - Graficas generadas para el Metodo del Codo, Silueta, distribucion de clusters, perfil de clusters y visualizacion PCA.

3. `resultados/`
   - CSV con metricas por valor de `k`, etiquetas de cluster y resumen de perfiles.

4. `Readme.md` /resultados
   - Informe con metodologia, numero optimo de clusters, metricas, interpretacion y conclusiones.

## Orden de ejecucion

1. Verificar que exista `PREPROCESAMIENTO_LIMPIEZA_DATOS/8_dataset_preparado_ml.csv`.
2. Abrir y ejecutar `1_notebook_clustering.ipynb`.
3. Revisar las graficas en la carpeta `graficas`.
4. Revisar el informe `informe_resultados.md`.

## Resultado esperado

Identificar segmentos o patrones ocultos dentro de las reservas hoteleras mediante K-Means.
